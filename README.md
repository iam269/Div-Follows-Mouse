# Div Follows Mouse 🖱️✨

An interactive web page where a div element smoothly follows your mouse cursor around the screen! Perfect for demonstrating mouse tracking and CSS animations.

## Features
- 🎯 Smooth mouse tracking
- 🎨 Customizable div styling
- 🚀 Lightweight and fast

## Live Demo
Check out the live demo: [https://itsiamdev.github.io/Div-Follows-Mouse/](https://itsiamdev.github.io/Div-Follows-Mouse/)

## How to Use
Simply open `index.html` in your web browser and move your mouse around to see the div follow!

## Technologies Used
- HTML5
- CSS3
- JavaScript
